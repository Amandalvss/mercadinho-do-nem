# Mercadinho do Nem - Sistema de Gestão

MVP desenvolvido para a disciplina de Projeto de Software.

## O Problema
O Mercadinho do Nem, em Japeri (RJ), usava um caderno manual para registrar vendas, despesas e fiados, o que causava erros e falta de controle.

## A Solução
Uma aplicação web responsiva focada na simplicidade, que permite:
- Registro rápido de vendas;
- Controle de saldo devedor de clientes (fiado);
- Cálculo automático do valor da venda.

## Tecnologias Utilizadas
- **Back-end:** Python + Django
- **Front-end:** HTML, CSS
- **Banco de Dados:** SQLite
